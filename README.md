# PocketBudget PWA

Simple monthly budgeting tool with category spending charts and alerts.

### Features
- Income/expense tracker
- Pie chart breakdown
- Budget limits & warnings
- Data backup/restore

### Tech Stack
- **Vite** & **TypeScript**
- **Workbox / Vite PWA Plugin** for offline capabilities
- **IndexedDB & LocalStorage** for persistent state

### Getting Started
```bash
npm install
npm run dev
```
